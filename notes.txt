# MCP Nexus — Complete Enterprise Application Design Prompt

Design and build the **complete MCP Nexus enterprise SaaS application** as a cohesive, production-quality application — not as a collection of disconnected demo screens.

## 1. Product Identity

**Product Name:** MCP Nexus

**Tagline:** Connect. Govern. Orchestrate.

**Product Description:**

MCP Nexus transforms existing enterprise APIs into governed MCP capabilities and enables AI agents to securely orchestrate applications, knowledge, and enterprise workflows through a common intelligent experience.

The platform enables enterprises to:

* Register existing enterprise applications
* Discover APIs from Swagger/OpenAPI specifications
* Select APIs that should become AI-accessible capabilities
* Generate application-specific MCP servers
* Expose selected APIs as MCP Tools
* Govern MCP Tool access between applications
* Orchestrate multiple MCP servers through an AI Agent
* Search enterprise knowledge
* Combine enterprise knowledge and live application data in one AI conversation
* Request and approve access through conversational workflows
* Provide a common enterprise AI chatbot

The most important product concept is:

**Connect existing enterprise applications to AI safely and easily.**

# 2. Overall Application Design

Create a **modern, premium enterprise SaaS application** comparable in quality and polish to products such as Datadog, Atlassian, Microsoft Azure, ServiceNow, and modern enterprise AI platforms.

Use a **1440 × 1024 desktop canvas** for all major screens.

The application must feel like a real enterprise platform that could realistically be deployed inside a large organization.

Do NOT design isolated mockups. Build a consistent application experience with:

* Shared navigation
* Shared header
* Shared components
* Consistent terminology
* Consistent spacing
* Consistent colors
* Consistent interaction patterns
* Consistent application states
* Realistic enterprise data

# 3. Visual Design Language

Use a **light enterprise theme**.

### Background

* White content areas
* Very light gray page backgrounds
* Very subtle blue/gray surfaces

### Primary Colors

* Blue for applications and APIs
* Indigo for MCP and AI
* Purple/cyan subtle accents for AI
* Teal for Knowledge Hub

### Status Colors

* Green = successful/active
* Amber/orange = pending/warning
* Red = actual errors or destructive actions only

### Component Style

Use:

* 10–14px rounded corners
* Thin subtle borders
* Soft shadows
* Spacious layouts
* Modern enterprise icons
* Clean tables
* Status badges
* Expandable cards
* Tooltips
* Modal dialogs
* Multi-step wizards
* Toast notifications

### Typography

Use Inter or a similar modern enterprise font.

### Avoid

* Dark backgrounds
* Heavy gradients
* Excessive animation
* Excessive colors
* Cartoon-style UI
* Overly rounded cards
* Crowded dashboards
* Decorative elements that do not communicate information

The design should communicate:

**Enterprise + AI + Security + Governance + Automation**

**Application:** Customer Transaction Portal

**MCP Server:** Customer Transaction Portal MCP

Create **one complete MCP Nexus application** with a unified information architecture, shared navigation, reusable components, consistent data, realistic workflows, and connected user journeys.

The final result should look like a real enterprise SaaS product ready for a major enterprise architecture demonstration or hackathon presentation.

The core visual story must always communicate:

**Connect. Govern. Orchestrate.**
